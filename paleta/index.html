Justificación Técnica

La paleta combina neutros oscuros para el fondo y las superficies con mint como color de identidad. Así se crea profundidad sin destacar sobre el contenido. El azul se usa para las acciones principales, lo que las distingue de los elementos decorativos. Conseguimos legibilidad con un texto claro sobre fondos oscuros y texto oscuro sobre el mint, combinaciones de alto contraste. Además, limitar cada color a un uso concreto ayuda a reconocer rápidamente la marca, la información y las acciones.
